# 重製端與未修改 DOSBox 原版測試報告（2026-08-11）

## 目的與範圍

驗證重製端敵方回合窄切片、戰鬥後城鎮／整備路由，並以未修改原版 `FD2.EXE`／固定 `FD2.SAV` 在 DOSBox 建立畫面錨點。本報告不宣稱逐像素等價（parity），也不把不同狀態比較成同狀態證據。

## 精確命令與輸入時間線

重製端使用 `fd2-go-test-local:latest`，`docker run --rm --network none --memory 3g --cpus 2 --pids-limit 384 --user "$(id -u):$(id -g)"`，掛載 `$PWD:/src:ro`，並在 `/src/remake` 執行 `timeout 900s xvfb-run -a -s "-screen 0 1280x1024x24" go test ./... -count=1`（`GOMAXPROCS=1`、`GOFLAGS=-p=1`）。精準命令同樣在 `xvfb-run`／`timeout 300s` 內執行：

- `go test ./cmd/fd2 -run 'TestAIStepConsumesVerifiedMode1BlockedCoordinate|TestAIStepStopsMode1WithoutMovementProvenance|TestAIStepConsumesVerifiedMode2PhysicalPlan|TestAIStepStopsMode2WithoutMovementProvenance|TestAIStepConsumesVerifiedMode5EventPlan|TestAIStepStopsMode5WithoutMovementProvenance|TestAIStepConsumesVerifiedMode7DestinationPlan|TestAIStepStopsMode7WithoutMovementProvenance|TestAIStepConsumesVerifiedMode3AndMode9RawTargetPlans|TestAIStepStopsMode3AndMode9WithoutMovementProvenance|TestAIStepConsumesVerifiedMode4AndMode10DestinationPlans|TestAIStepStopsMode4AndMode10WithoutMovementProvenance|TestAIStepConsumesVerifiedMode0NearestFallback|TestAIStepStopsMode0WithoutMovementProvenance|TestAIStepConsumesVerifiedMode8Completion|TestAIStepConsumesVerifiedMode11StagesInNativeOrder' -count=1 -v`
- `go test ./internal/campaign -run 'TestCampaignFullChapter16BattlePreservesTownShopPreparationBoundary|TestCampaignFullPostBattleTownContractMatchesOriginalShopChapters' -count=1 -v`

測試夾具（fixture）以 3×1 戰場先驗證 mode 1 blocked-coordinate movement-only、mode 2 移動／攻擊、mode 5 事件格尾端，再驗證
mode 11 兩段 stage；戰後測試沿 `battle_ch16 → postbattle_ch16_persist → town_ch17 → preparation → battle_ch17`，並覆蓋商店／整備章節契約（shop/preparation contract）。

原版使用 `fd2-dosbox-screenshot-local:latest`，來源 `org_game/炎龍騎士團/FLAME2` 唯讀掛載至 `/source`，容器內複製至可寫 `/game` 沙箱；命令為：`timeout 120s /usr/local/bin/fd2-dosbox-screenshot "wait:8;key:Escape;wait:2;key:Return;wait:4;shot:continue" "fixed 12000"`。輸入時間線是啟動 8 秒、Escape、等待 2 秒、Return、等待 4 秒、擷取 continue。

## 結果

### 通過

- mode 2 AI 測試通過：完成 raw 計畫的移動／攻擊並結束回合。
- mode 5 AI 測試通過：完成 raw event grid 的事件格移動、state tail 提交與回合結束。
- mode 5 缺少 movement provenance 時通過失敗即關閉測試：不建立行走／攻擊、不改寫事件或回合。
- mode 7 AI 測試通過：完成 raw 目的地的 movement-only 行走、`+0x05=1` 提交與回合結束；缺少 movement provenance 時維持失敗即關閉。
- mode 3／9 AI 測試通過：依 raw `+0x08` 首筆查找完成 movement-only 行走；mode 3 的 map-range write 與 mode 9 的不寫入分支均符合，缺少 movement provenance 時維持失敗即關閉。
- mode 4／10 AI 測試通過：依 raw `+0x35/+0x36` 完成 movement-only 行走與 map-range write，不寫入 `+0x05`；缺少 movement provenance 時維持失敗即關閉。
- mode 0 AI 測試通過：依 raw nearest fallback 完成 movement-only 行走且不寫入 map-range；缺少 movement provenance 時維持失敗即關閉。
- mode 1 AI 測試通過：依唯一 raw blocked-coordinate 完成 movement-only 行走且不寫入 map-range；缺少 movement provenance 時維持失敗即關閉。
- mode 8 AI 測試通過：共同 raw 行動完成分支可提交回合。
- mode 11 AI 測試通過：兩段 native stage 依序完成，MP、目標 HP、turn 更新。
- 第 16 戰戰後城鎮／整備邊界測試通過。
- 全 shop/preparation chapter contract 測試通過（shop 02–22、26–27；preparation 23–30）。
- 未修改 DOSBox 啟動／CONTINUE 命令完成並產生畫面，原始來源未被寫入。

### 未驗證與阻塞點（blocker）

本輪 DOSBox 探測未可靠進入已知敵方 AI 原始（raw）狀態，因此沒有重製端／原版同一 `FD2.SAV`、鏡頭（camera）、游標（cursor）、回合（turn）、幀（frame）的配對；mode 11 只能列重製端 E1，不能升格 DOSBox E2 或逐像素等價（parity）。第一次精準重跑漏包 `xvfb-run`，Ebiten 因缺少 `DISPLAY` 在測試初始化前失敗；補上 Xvfb 後測試均通過，屬命令環境錯誤而非遊戲邏輯失敗。
