已證實的最小資料流：

- `sub_29F72` 的 `0x2A205..0x2A275` 與 `sub_1ECC7` 的對應尾段，
  只對來源 raw `+6 == 2`、目標 raw `+7 >= 68` 計算攻擊 EXP。

  不能用按 race/class 合併的舊 `ExpPerLevel` 冒充此值。

  分母的來源等級 byte 加 30；其餘直接用等級。
- `0x2A243..0x2A25B`：`0F AF D0` 後 `F7 FB`，以整數計算
  `基數 × 目標等級 / 有效來源等級`。目標存活才在 `0x2A267..0x2A275`
  乘本次傷害後再 `idiv` 目標 MaxHP；兩階段都取整，不能最後才截斷。
