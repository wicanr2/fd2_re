# 第一關推廣片與 DOSBox 對拍規格

狀態：CONFORMED（2026-08-30）

本規格修正 v0.1.0 推廣片中不受控的第一關輸入，並把 DOSBox 原版與重製版的
動態比較納入正式成片。證據與推論分級見
[`ch01-promo-menu-correction-20260830.json`](data/ui-traces/ch01-promo-menu-correction-20260830.json)。

## 畫面契約

- 第一關部署格沿用 `ch01.json`；現有證據支持四名角色的欄位順序，不因舊影片
  的錄製時點而猜測性改寫。
- 空游標開啟系統選單時，四格選單必須靠近目前游標格。缺少原生畫面 admission
  時仍使用目前游標，不得退回 `(0,0)`。
- 第一關實機片段只送出抵達戰場及展示功能所需的有限輸入；不得再用固定 24 次
  Enter 穿過未知數量的對話與戰鬥狀態。
- DOSBox 與重製畫面並排時，優先使用同一份合法 `FD2.SAV` 的 current-runtime
  狀態。若動畫相位無法鎖定，片中文字必須標示「相近狀態比較」。

## 驗收條件

1. Docker 測試覆蓋空游標後備錨點，以及既有原生／選取單位錨點。
2. Docker 錄製的第一關片段中，隊伍仍位於初始物化隊形，系統選單不在左上角。
3. 成片包含 DOSBox 原版與重製版的動態並排段落，且標籤可辨識。
4. 以 `ffprobe`、黑幀／靜音檢查及聯絡表抽樣驗收影片；所有容器在完成後退出。
