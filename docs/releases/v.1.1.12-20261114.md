# v.1.1.12-20261114 發行說明

本版修正玩家回報的兩個問題：法術與其他指令拿不到經驗值，以及第一次按 F2 或 F11 會卡住畫面。三平台完整版以新引擎重新打包，素材與 `v.1.1.11-20261113` 相同。

Go 版自 `v.1.1.11` 起凍結，改寫主線是 Rust 版。本版是使用者 2026-11-14 同意的一次例外，只含這兩項修正，之後照舊凍結。

## 本次修正

| 項目 | 修正內容 |
|---|---|
| 指令經驗值 | 我方以法術或其他指令攻擊、回復、附加狀態、傳送或使用行動術後，依原版公式得到經驗並可升級。舊版只有物理攻擊會給經驗。 |
| 第一次 F2／F11 | 第一次切到 HD 時改在背景載入素材，畫面照常更新並顯示「HD 主題素材載入中，完成後自動切換」，載入完成後自動切換。舊版在這段時間（約 3～4 分鐘）畫面停住，Windows 會顯示「沒有回應」。 |

經驗值的公式取自原版執行檔的經驗累計寫入端，玩家每次行動結束時發放，和物理攻擊相同。證據見 [`fd2_command_experience_writers_20261114.json`](../data/ida/fd2_command_experience_writers_20261114.json)，本版沒有新增原版對拍。

## 建置與驗證範圍

三平台引擎由來源提交 `5747771c` 在本機 Docker 建置，方式同 v.1.1.11，見[打包文件 §4.4](../knowledge-base/41-packaging.md#44-本機-osxcross-建置使用者2026-11-13定案)。

| 平台 | 已驗證 |
|---|---|
| Linux | 引擎包與完整包在 Xvfb 下自檢；完整包開場受控截圖 |
| Windows | 引擎包與完整包在 Wine 10 下自檢；完整包開場受控截圖 |
| macOS 通用版 | 只做靜態檢查：雙架構、arm64 簽章、只連結系統框架、最低 macOS 11.0 |

三包各 54577 份素材已獨立解包逐檔核對，素材清單與 v.1.1.11 逐位元組相同。Linux 與 Wine 的開場截圖相同，也與 v.1.1.11 的截圖相同（SHA-256 前綴 `affb593a`）。兩項修正的驗證在重製端：經驗值有單元測試與正式指令流程測試；F2／F11 以真實 HD 包量測，第一次按下立即回應，約 3～4 分鐘後自動切換。`cmd/fd2` 全套測試的失敗名單與修正前相同，皆為測試環境缺 HD 素材的既有失敗。

macOS 版在 Linux 上無法執行，沒有任何執行證據；Windows 的自檢在 Wine 執行，不等於原生 Windows。Windows、macOS 未簽署，macOS 未公證，首次開啟需右鍵選「打開」。
