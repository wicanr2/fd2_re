# v.1.1.15-20261116 發行說明

本版加入遊戲內滑鼠、手把，以及「手把與自訂按鍵」設定面板。三平台完整版以新引擎重新打包，原版與 HD 素材與 `v.1.1.14-20261115` 相同，另加四個語系的設定面板文字檔。

Go 版自 `v.1.1.11` 起凍結，改寫主線是 Rust 版。本版是使用者 2026-11-16 同意的第四次例外，只含這項功能，之後照舊凍結。

## 新功能

| 項目 | 內容 |
|---|---|
| 滑鼠 | 指向地圖格子時游標跟過去；指向指令環、標題選單、讀檔槽、城鎮選單與選項框時改選該項。左鍵＝Enter、右鍵＝Esc、滾輪＝上下。只有滑鼠移動或按鍵時才作用，靜止的滑鼠不會干擾鍵盤操作。 |
| 手把 | 十字鍵或左搖桿＝方向鍵，A＝Enter，B＝Esc，X＝Space，Start＝開設定面板；肩鍵與 Select 預設不綁。搖桿有防飄移死區。視窗失焦或手把插拔時放開全部輸入，要等按鈕放開、搖桿回中央才再讀取。 |
| 手把與自訂按鍵 | 按 **F12** 或手把 **Start** 開啟。表格分「動作／鍵盤／手把」三欄、依移動與游標、確認與取消、系統功能鍵分組。選一列按 Enter 或手把 A，再按要指定的鍵；重複綁定會先提示。Delete／X 清除，R／Y 恢復預設，Esc／B 返回。下方可調搖桿防飄移。設定即時存到使用者目錄的 `controls-settings.json`，與存檔分開。 |
| 除錯 HUD | 開發用的除錯 HUD 改為 **Ctrl+F12**。 |

- 介面參考《魔法門 III》中文化版的桌面按鍵設定（分組表格版面）。
- 商店、整備、教會、旅館、物品欄、指令格與法術表目前只支援滾輪、左鍵確認與右鍵取消；滑鼠指向不會改這些清單的選取列。
- 沒有滑鼠移動或手把輸入時，遊戲行為與 v.1.1.14 相同。

## 建置與驗證範圍

三平台引擎由來源提交 `231b5d98`（功能本身是 `7c710b34`）在本機 Docker 建置，方式同 v.1.1.11，見[打包文件 §4.4](../knowledge-base/41-packaging.md#44-本機-osxcross-建置使用者2026-11-13定案)。

| 平台 | 已驗證 |
|---|---|
| Linux | 引擎包與完整包在 Xvfb 下自檢；完整包開場受控截圖 |
| Windows | 引擎包與完整包在 Wine 10 下自檢；完整包開場受控截圖 |
| macOS 通用版 | 只做靜態檢查：雙架構、arm64 簽章、只連結系統框架、最低 macOS 11.0 |

三包各 54581 份素材已獨立解包逐檔核對（比 v.1.1.14 多四個語系的 `controls.json`），原版與 HD 素材清單與 v.1.1.14 相同。Linux 與 Wine 的開場截圖相同，也與 v.1.1.14 相同（SHA-256 前綴 `affb593a`）。

功能本身的驗證在重製端：
- 新增 21 項單元測試：綁定轉換、衝突確認、清除與恢復預設、設定檔讀寫與損壞檔、滑鼠指向地圖格／指令環／選單列、左右鍵與滾輪、手把按鈕／死區／連發、失焦與插拔放開、F12 與 Start。
- 設定面板在 Xvfb 下以原版美術與 HD 介面各截一張，版面已人工檢視。
- 原版模式的 Go 黃金畫格（開場與第一章）序列雜湊不變，第一章 `checkpoints.jsonl` 不變；`cmd/fd2` 全套測試的失敗名單與 v.1.1.14 相同（19 項，皆為測試環境缺 HD 素材的既有失敗）。

macOS 版在 Linux 上無法執行，沒有任何執行證據；Windows 的自檢在 Wine 執行，不等於原生 Windows。Windows、macOS 未簽署，macOS 未公證，首次開啟需右鍵選「打開」。
