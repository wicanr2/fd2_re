# 《炎龍騎士團 2》重製版 v0.1.1

這是第一個公開版本的操作與呈現修正版。它保留 v0.1.0 的戰役、四語與封包契約，
並修正第一關隊伍進場節奏及戰場功能選單位置。

## 下載內容

- `FD2-v0.1.1-linux-x86_64.AppImage`
- `FD2-v0.1.1-windows-x86_64.zip`
- `FD2-v0.1.1-macos-universal.dmg`
- `FD2-v0.1.1-macos-universal.tar.gz`
- `SHA256SUMS`

公開附件不含原版執行檔、美術、音樂、字型或其他著作權素材。玩家必須合法持有
原版並在本機產生分離素材；缺少素材時，重製版維持失敗即關閉。

## 本版修正

- 戰場四格功能選單改為錨定目前選取方塊附近，不再固定出現在左上角；同一契約
  已抽測早期 `map0`、中期 `map25` 與後期 `map28`。
- 第一關序章四人隊伍依 `ACTING(0)` 同步向哈瓦特小屋方向移動六格。
- 七拍移動時基由錯誤的 60 Hz 解讀修正為約 18.2065 Hz 的 DOS PIT 規格近似；
  remake 不追逐 BIOS 或硬體逐週期一致。
- README 新增 33 張原版戰場、96 組戰場角色與 96 組對話頭像的低解析研究總覽；
  完整原版分離素材仍只保存於私人庫與本機完整版。

## 本機完整版

含玩家私有原版素材的 Linux、Windows 與 macOS 完整版已在本機重新組裝；其
`FD2-LOCAL-FULL.json` 均標示 `public_distribution: false`，不會上傳 GitHub Release。

## 已知限制

- 靜態同狀態 22 像素差不能證明第一關所有動畫逐幀一致。
- 新抓取的 DOSBox 畫面只抵達標題，不能當作新的第一關動態證據；動態結論仍依
  已分級影片收據與重製端決定性測試。
- Windows／macOS 工作流程不能取代玩家實體桌面長時間驗收；macOS 尚未簽章或公證。
- 現代重繪目前只有索爾頭像風格樣張，尚未替換正式遊戲素材。
