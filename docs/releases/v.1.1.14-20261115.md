# v.1.1.14-20261115 發行說明

本版修正玩家回報的 HD 畫面問題：開啟 HD 美術時，每句對白期間整張地圖與地圖上的人物會變回原版像素圖，句與句之間又回到 HD，看起來像原版與 HD 交替切換。三平台完整版以新引擎重新打包，素材與 `v.1.1.13-20261115` 相同。

Go 版自 `v.1.1.11` 起凍結，改寫主線是 Rust 版。本版是使用者 2026-11-15 同意的第三次例外，只含這項修正，之後照舊凍結。

## 本次修正

| 項目 | 修正內容 |
|---|---|
| HD 美術下的對白 | 故事對白與戰場事件對白期間，背景地圖與地圖人物維持 HD。舊版自 v.1.1.11 起，每句對白從開框到收框會把整張畫面換成原版像素圖。 |

- 原因：對白畫面以整張原版 320×200 畫格呈現，蓋掉底下已畫好的 HD 世界。HD 頭像本身一直正常。
- 做法：HD 美術開啟時，每句對白先以兩種底色重放開框、逐字頁與收框，兩次相同的位置就是對白實際畫到的像素，呈現時只疊這些像素。原版美術、非繁中分頁捲動或重放失敗時照舊畫完整畫格。
- 句子進行中才按 F2 切到 HD 的那一句仍顯示完整原版畫格，下一句起套用。

- HD 素材載入完成後仍常駐約 1.75 GiB，記憶體 4 GB 的電腦切到 HD 仍可能吃緊。

## 建置與驗證範圍

三平台引擎由來源提交 `1e23657a`（修正本身是 `ce192d22`）在本機 Docker 建置，方式同 v.1.1.11，見[打包文件 §4.4](../knowledge-base/41-packaging.md#44-本機-osxcross-建置使用者2026-11-13定案)。

| 平台 | 已驗證 |
|---|---|
| Linux | 引擎包與完整包在 Xvfb 下自檢；完整包開場受控截圖 |
| Windows | 引擎包與完整包在 Wine 10 下自檢；完整包開場受控截圖 |
| macOS 通用版 | 只做靜態檢查：雙架構、arm64 簽章、只連結系統框架、最低 macOS 11.0 |

三包各 54577 份素材已獨立解包逐檔核對，素材清單與 v.1.1.13 逐位元組相同。Linux 與 Wine 的開場截圖相同，也與 v.1.1.13 的截圖相同（SHA-256 前綴 `affb593a`）。

修正本身的驗證在重製端：
- 新增遮罩測試，涵蓋四種對白控制碼，各跑繁中與英文、有無收框尾段；驗證對白實際畫到的像素都在遮罩內，以及退回完整畫格的條件。
- 以真實 HD 包重現第二章前的故事對白與第十七章的戰場事件對白，修正後對白期間地圖、人物與 HUD 維持 HD。兩者都是直接進場或測試夾具，不是一般玩家路徑。
- 原版模式的 Go 黃金畫格（開場與第一章）序列雜湊不變，第一章 `checkpoints.jsonl` 不變。
- 以真實 HD 包跑完整主題測試 15 項通過；`cmd/fd2` 全套測試的失敗名單與 v.1.1.13 相同（19 項，皆為測試環境缺 HD 素材的既有失敗）。

macOS 版在 Linux 上無法執行，沒有任何執行證據；Windows 的自檢在 Wine 執行，不等於原生 Windows。Windows、macOS 未簽署，macOS 未公證，首次開啟需右鍵選「打開」。
