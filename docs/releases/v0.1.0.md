# 《炎龍騎士團 2》重製版 v0.1.0

這是專案第一個公開里程碑：以潔淨室 Go／Ebiten 引擎保存並重現 1995 年
《炎龍騎士團 2》的戰役、戰鬥、城鎮與終局結構。

## 下載內容

- `FD2-v0.1.0-linux-x86_64.AppImage`
- `FD2-v0.1.0-windows-x86_64.zip`
- `FD2-v0.1.0-macos-universal.dmg`
- `FD2-v0.1.0-macos-universal.tar.gz`
- `FD2-v0.1.0-promo.mp4`：目前版本實際遊玩、第一關與四語切換推廣片
- `SHA256SUMS`：全部附件的 SHA-256

## 素材與啟動說明

公開封包只包含重製引擎、可編輯戰役／故事資料、四份官方語言包與授權正文，
**不包含原版執行檔、美術、音樂、字型或其他著作權素材**。玩家必須合法持有
原版，並依[`三平台打包與資產路徑說明`](../knowledge-base/41-packaging.md)將本機
分離素材放入使用者資料目錄。缺少玩家素材時，重製版會失敗即關閉，不會從網路
下載或以猜測內容替代。

- Linux：賦予 AppImage 執行權限後啟動。
- Windows：解開 ZIP 後執行 `fd2.exe`。
- macOS：目前未簽章；DMG 與 tar.gz 內是同一份 universal app。Gatekeeper、
  實體視窗、輸入、存檔與音訊仍待更多真機驗收。
- 遊戲中按 F4 可在繁體中文、簡體中文、日文與英文間原子切換；v0.1.0 只完成
  已接通語意鍵的基礎切片，不宣稱全部原版台詞都已翻譯。

## 本版可驗證成果

- 第一輪 60／60 個分層代表性抽樣通過，涵蓋戰役／戰間、戰鬥／敵方人工智慧、
  介面、存檔／持續隊伍及終局／平台。
- 正式標題、讀檔、第一關、玩家指令、敵方回合、城鎮、商店、教會、整備、
  第29／30戰與終局已有重製端正常路徑。
- Linux、Windows 與 macOS 原生工作流程在提交 `8e44fbc4` 重建；每包均通過
  具型別封包自我檢查、四語存在檢查、授權正文檢查及可攜雜湊。
- 推廣片由提交 `a98e7cec` 的相同行為程式重新擷取，走正式標題進入第一關，
  實際顯示四語切換；影音驗收為 H.264／AAC、1280×720、30 fps、71.5 秒，
  無長黑與長靜音。

## 已知限制

- 第一輪里程碑是預先定義的代表性抽樣，不代表 DOS 逐像素、逐音訊或逐週期一致。
- Windows／macOS 工作流程與封包自我檢查不能取代玩家實體桌面長時間驗收。
- macOS 尚未簽章或公證。
- 現代重繪美術尚未進入本版；忠實主題仍使用玩家自備、由原版分離的素材。
- 完整四語翻譯、圖形化編輯器與外部社群語言包管理介面仍是後續里程碑。
