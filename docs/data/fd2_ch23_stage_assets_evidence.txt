原版證據與位址空間
--------------------

主證據為
[`ida/fd2_ch23_post_ida.txt`](ida/fd2_ch23_post_ida.txt)。工具為使用者授權的
IDA Pro 9.4 Docker，並以 Capstone 5 Docker 交叉驗證；位址均是
FD2 LE linear address，不是檔案偏移。

- `sub_10652` 邊界：`0x10652..0x1088D`。
- raw chapter `0x17` 分支於 `0x107EF..0x10804` 將 selector `0x2A`
  （decimal 42）交給 `sub_111BA`，資源來自 `FDOTHER.DAT`。
- `0x107DD..0x107EA` 配置 `0xEA00` bytes，即 `312*192`。
- `0x10809..0x10820` 以 transparent `-1`、stride `0x138`（312）與
  staging owner 呼叫 `sub_4E63D`。
- `0x1083B..0x10842` 在 loader 完成後呼叫 `sub_24D22(0)`。
- raw entry 開頭是 little-endian width 312、height 192，其後是已驗證
  `0x4E63D` four-mode stream。

分離資產 READY 契約
----------------------

- 使用現有標準單幀路徑：`surfaces/FDOTHER_042/`。
- `resource.json`：
  - `kind=indexed_surface`
  - `asset_id=surface/FDOTHER_042`
  - `codec=fd2_4e63d_single_frame`
  - `status=decoded`、`evidence=confirmed`
  - source 固定為上述 FDOTHER identity、resource 42、raw size 59412。
- `frame.png` 必須是312×192、256色 indexed PNG；`mask.png` 必須是
  同尺寸 binary grayscale mask。透明 skip 不可轉成 palette index 0。
- `LoadSeparatedNativeCh23Stage` 固定檢查身分、resource、raw size、
  codec、幾何、indexed frame 與 binary mask；不讀取或回退 archive。
- `startNativeCh23Loop` 與 `prepareNativeCh22Aux` 必須共用這個 strict
  loader；缺包時在 staging 或 campaign mutation 前失敗即關閉。
- 驗收必須將 separated frame 與固定原版 `DecodeNativeCh23Stage`
  的 geometry／indexed pixels／mask 逐項比較，並執行兩個正式 owner
  的聚焦回歸與缺包拒絕。

------

的 loop、BIOS tick、DAC、campaign handoff 或未修改原版 E2。標準 DOS
時脈亦不是這個素材分離契約的阻擋。
