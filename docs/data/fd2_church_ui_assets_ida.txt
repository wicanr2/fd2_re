## 分離資產契約（DATA-READY／RUNTIME-E1，2026-08-29）

- 標準目錄：`ui/fdother_014_church/`；metadata：`resource.json`。
- 固定 `kind=fdother_lmi1_church_ui`、`asset_id=ui/FDOTHER_014/church`，並保存
  archive hash、resource 14 與51,157-byte raw size。
- `four_mode_frame`：entries 0、23..31；每筆輸出 indexed `frame.png` 與 binary
  `mask.png`。
- `opaque_high_run`：entries 1、3..10、16；每筆只輸出 indexed `frame.png`。
- `raw_indexed_opaque`：entry15；只輸出 indexed `frame.png`。
- metadata 必須恰含上述21筆且 index 不重複；codec、幾何、相對路徑、PNG mode、
  mask mode及來源任一不符即失敗即關閉。production 不得對 resource14 回退 archive。
- 驗收：所有 separated pixels／masks 與對應原始 parser 逐位元組一致；缺 pack
  必須拒絕；教會主選單、轉職、物品轉交與復活的既有 compositor 測試不變。

本契約不涵蓋同一 loader 仍使用的 FDOTHER #5 dialogue／digits 或 #2 choices；
它們必須在各自 canonical 切片完成後移除剩餘 `nativeFDOTHERPath()` owner。

正式 `fd2-asset-import` 現已輸出21筆 metadata／indexed PNG／binary mask；
`fdother.LoadSeparatedChurchUIAssets` 嚴格驗 provenance、完整集合、codec、幾何與
PNG mode。所有 entry pixels／masks 已在 Docker 中與固定 raw resource 逐位元組
比較通過，缺 pack 會拒絕。`loadNativeClassUIAssets` 已不再讀取或解析 resource14，
轉職與四項教會服務的正式 Ebiten 聚焦回歸亦通過。因此 resource14 固定資產達
`RUNTIME-E1`；#5／#2 的剩餘 archive 依賴與 DOSBox `PLAYER-E2` 限制不變。
