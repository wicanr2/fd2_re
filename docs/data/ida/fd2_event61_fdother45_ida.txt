已證實結論
------------

1. `0x35790` 的 selector 是 decimal 45，且資源來自 `FDOTHER.DAT`。
2. consumer 依原始順序使用 frame index 0..58，共59幀；每幀後呼叫
   `sub_17AA9(2)`。
3. `sub_2935B` 呼叫參數已直接固定為 destination base `0xABCE4`、
   stride 320、transparent `-1`。
4. raw entry 的 frame table 計數為59；59筆 descriptor 皆為
   `x=0,y=0,width=8,height=2`，每筆 raw descriptor／payload 長度31 bytes。
5. 這是逐幀累積寫入同一 destination 的 indexed／transparent 演出。
   PNG 輸出必須分離 indexed pixels 與 binary source mask，不可把透明
   skip 轉成 palette index 0。
