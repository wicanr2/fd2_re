consumer 與生命週期
-------------------
- 每幀解碼後，`0x2053B cmp [arg_0],1` 且 `0x20542 test esi,esi`；只有 ANI #1
  的第一幀（`esi == 0`）執行：
  `push 1`、`push esi`、`push resource_ptr`、`call sub_25A96`。
  因此播放 selector 固定為 0。
- 動畫自然播完或可略過輸入離開後共用 `0x20586..0x205A6`：若資源指標非零，
  以 selector `-1` 呼叫 `sub_25A96`，再 `free(resource_ptr)`。
- `sub_25A96`：`0x25A96..0x25B45`。selector 非 `-1` 時，以巢狀目錄欄位
  `[entry+6]` 作 sample 起點、`[entry+0xA]-[entry+6]` 作長度，交給音訊後端；
  selector `-1` 只走停止既有 handle 的路徑。

語意與限制
----------
- 已證實：FDOTHER #78 是 ANI #1 專用的 selector 型 PCM 音效庫；selector 0 在第一幀
  啟動，動畫結束或略過時停止。
- 已證實：#78 的畫面責任不存在；舊文件把它與白色泛光連結是錯誤斷言。
- 已證實：資源是兩筆目錄項（一筆非空 sample、一筆 0-byte 尾哨兵）。
- 未知：音效的自然語言名稱。正式資料只記 `ani1_frame0_companion`，不可猜成爆炸、
  閃光或 logo 音。
- hardware-spec approximation：分離 OGG 使用 unsigned 8-bit mono／11025 Hz 的既有
  音訊契約；不宣稱 DOS DAC／PIT 逐週期一致。
