前者保存原版普通 LMI1 的全部138項，後者只為已有 caller 證據的 raw／opaque／

另一種 codec。

所有 metadata 必須同時固定 archive identity、resource index、raw size、raw MD5、
raw SHA-256、codec、entry index、幾何與相對路徑。任何缺漏、重複索引、錯誤
identity、非 paletted indexed PNG、錯誤幾何或未知 codec 都必須原子拒絕；正式
runtime 不得回退開啟 FDOTHER.DAT。固定原檔 decoder 只保留給 importer 與 oracle。

本切片不證明 #55 的玩家可見圖像名稱、不重新命名 #3 LUT 視覺效果，也不把
#5/#6 的每一個未命名 entry 升格為具體法術或道具語意。這些高階語意仍依各自
caller／consumer 證據分級。
