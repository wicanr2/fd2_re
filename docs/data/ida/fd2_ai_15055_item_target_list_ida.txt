## 與 0x1567E producer 的閉合關係

- `sub_1567E (0x1567E..0x15880)` 在每個 candidate destination 先產生完整
  target list，再於 `0x157F0..0x157FD` 將 item ID、target count 與清單傳給
  `sub_15880` 評分。
- strict-greater winner 在 `0x15808..0x15823` 寫入 score、destination X/Y 與
  inventory slot 到 `[0x53C33/37/3B/3F]`。原版不把該候選清單存成全域；
  `0x15055` 依同一 destination 與同一 item row 重建它。
- 重製端可以保存 winner 當時已算出的 detached raw target list，等價取代原版
  第二次幾何計算；但必須完整保存順序，並在執行前重新驗證 actor、item row、
  slot 與所有 raw index。這是資料流等價實作，不表示原版有 target-list 全域。

## 重製規格邊界

- `AIPlan` 必須保存 `ScoreNativeAI1567E` winner 的完整 raw target-index list，
  不得只保存 `TargetIndices[0]`。
- 正常 producer 目前只有 item type `5`、`13`、`20`、`21`、`24` 能取得正分；
  runtime 只接既有已閉合的 HP restore 與 command-damage transaction。
- item ID／slot、完整 target list、raw record、command row 或 resistance 任一缺失
  時失敗即關閉，且不得消耗行動、物品、HP 或 RNG。
- 本切片只關閉數值／存檔狀態交易（RUNTIME-E1）。`0x20C6F` 各 item 分支的

  PLAYER-E2。
