FD2 pending code 1／FDOTHER #79 固定呈現（IDA Pro 9.4）
=======================================================

日期：2026-08-29

輸入、工具與位址空間
--------------------

  SHA-256 `222b7d067ad4450eb9c5f6e6bce1797d54bb050417ba39ced6067f8039f28c4f`。
- `FDOTHER.DAT`：3382481 bytes；MD5 `22f56e5027edc7c766ad34ca4e5aca93`；

- 第一工具：合法 IDA Pro 9.4，`fd2-ida-authorized-local:latest`，一次性無網路

- 位址均為 IDA DOS Linear Executable 線性位址；保留原始名稱 `sub_22E5C`、
  `sub_2935B`、`sub_1F525`、`sub_1F882`。

caller 與固定路由（已證實）
---------------------------
- `sub_22E5C` 邊界 `0x22E5C..0x22EF6`；唯一直接 caller 是主迴圈
  `0x25DE5`。外層只在 raw `[0x53ECC] == 1` 時呼叫，之後清 pending code。
- 函式不讀章節索引、FDFIELD 或 turn-event table。因此「世界地圖」、
  「第 1 章中場」或「增援 consumer」均不是可沿用語意。

直接順序與參數（已證實）
-------------------------
1. `0x22E67..0x22E6B` 呼叫 `sub_25977(-1,1)`：沿用已閉合 BGM ABI，停止目前配樂。
2. `sub_17AA9(1)`，再呼叫 `sub_1F882` palette 前置。
3. `0x22E82` 以常數 `0x4F` 經 `sub_111BA` 載入 FDOTHER #79。
4. `memset(0xA0000,0,0xFA00)` 清 320×200 indexed framebuffer。
5. `sub_2935B(resource,0,0xA0000,320,-1)` 呈現 frame 0；`sub_1F525` 執行
   65 個 phase（64→0）、每 phase 2ms 的 palette 淡入。
6. `sub_17AA9(9)` 後，以相同 framebuffer／stride／透明 sentinel 呈現 frame 1。
7. `sub_17AA9(36)`，再把 resource pointer 交給既有釋放尾端 `0x15E94`。

`sub_2935B`（`0x2935B..0x2939D`）以 selector×4 讀 `[resource+8]` offset，
從 frame descriptor 的 `+0/+2` 取得 X／Y，把 `descriptor+9`、X、Y、destination、
stride、transparent 傳給 `sub_4E63D`。這與受版控 `ParseFrames`／四模式 RLE 契約一致。

資源形狀（已證實）
------------------
- FDOTHER #79：6801 bytes；MD5 `5f7eeeeff593ad7a067af167ef92670e`；
  SHA-256 `34bb99917cdfd6b268674d7c1cf201cc3749cf3a58c574161dc5d37a36781373`。
- frame-table count 2；offsets `0x10`、`0x18D7`。
- frame 0：`X=69, Y=61, 181×75`。
- frame 1：`X=130, Y=141, 55×8`。
- 兩幀都使用 caller 當下的 palette；#79 沒有獨立 palette resource。

證據分級與停止線
----------------
- 已證實：raw pending code 1 的固定呈現順序、兩個 selector、座標、framebuffer、
  stride、透明模式、淡入與等待值。
- 未知：兩幀的玩家可見高階名稱、哪些逐章 writer 在何種玩法條件產生 code 1，
  以及原版當下 palette 的所有來源分支。
- 因此可建立無高階命名的 separated frame bank 與 typed schedule；只有正式
  pending-code producer／consumer 接縫閉合後才能接入 Game。不可用測試注入或
  章節猜測冒充一般玩家路徑。
