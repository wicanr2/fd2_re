- `event_state[12]==0` 的正式資料路徑依序消費索引 `5,7,8,10,11`，共18句。
- `event_state[12]!=0` 的正式資料路徑依序消費索引 `6,7,9,10,11`，共33句。
- 41句是兩條互斥分支的可編輯資料總量；單次戰後流程不得同時播放41句。
- `sub_24E80` 從 runtime count 讀取掃描上界，並沒有把70寫死。重製正常第26戰
  入口由16名部署角色加 map25 group0的41筆形成57-slot；70是完整可編輯單位檔的
  資料形狀，不可再冒充唯一正常玩家 frontier。binding 明列57與既有70兩種可
  驗證形狀；此 runtime 投影屬「強推論」，不改寫原始 handler 的動態count語意。
- `FFEE` 是下框、`FFEF` 是上框；每句仍必須保存 operand、原始換行、分頁及
  glyph token。缺任一 tuple、映射不唯一、行數不等或出現未支援控制字時，正式
  binding 必須失敗即關閉（fail-closed）。
