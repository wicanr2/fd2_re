```text
0x1F8E3  83 C4 0C           add esp,0Ch

...
0x1FF66  FF 74 24 54        push [esp+arg_50]

```

較早的 `fd2_title_scroll_schedule_ida.txt` 把 `call sub_111BA` 寫成 `0x1F8DB`；
重新由 IDA 9.4 匯出的原始 bytes 證明 call 起點是 `0x1F8DE`。舊位址保留作勘誤
追溯，不再作直接指令定位。

## 巢狀容器（已證實）

固定版 resource #77 為 52,031 bytes；MD5
`3c0a8e570be878a9eea436c7d79375aa`，SHA-256
`4276bfc6bf4b9f7ae0815f4f15a8f74aff33c5c29d4a2b5d2a5a6ec30540ce13`。

offset 為 `26, 41359, 45636, 45796, 52031`。前四筆是非空 PCM，最後一筆

## selector 與 consumer（已證實）

`sub_25A96 (0x25A96..0x25B45)` 與 `sub_25B45 (0x25B45..0x25BF4)`
分別操作 `dword_53EE4`／`dword_53EE8`。兩者以 `index*4` 讀取
`[entry+6]` 與 `[entry+0xA]`，計算 `start=base+offset`、
`length=end-start`，再依序呼叫 `sub_391D1`、`sub_39344`、
`sub_3975E`、`sub_39448`。因此 #77 是可由 selector 選取的 raw sample bank，
不是未被使用的前導 blob。

```text
0x1FBC9  push 1
0x1FBCB  push 0
0x1FBCD  push #77 pointer
0x1FBD1  call sub_25A96

0x1FD1C  push 1
0x1FD1E  push 3

0x1FE6F  cmp eax,48h                ; H
```

## 重製映射與停止線

- `selector 2` 可接標題主選單的上／下移動，`selector 1` 可接確認；這兩項由
  同一輸入分支直接證實。
- `selector 0` 與 `selector 3` 先完整分離，但在各自精確 runtime 時點未形成
  可審查排程前不猜接。尤其不以人耳印象命名 sample identity。
- 取樣資料形狀為 unsigned 8-bit mono；11025 Hz 依專案硬體規格停止線記為
  `hardware-spec_approximation`，不再追 PIT／DAC／`.DIG` driver 逐週期時序。
- 本證據可授權 `DATA-READY` 與標題選單的窄 `RUNTIME-E1`；不宣稱完整開場音訊
  或一般玩家原版／重製人耳配對已達 `PLAYER-E2`。
