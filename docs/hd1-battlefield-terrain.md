# HD1 戰場地形圖冊

30 個主線戰場各列一張獨立 HD 畫面，依正式章名排列。點選圖片可放大。

畫面由重製引擎完整繪製，以受控相機選取代表區域。已核對原版／HD往返、角色資料、亂數與章界保存保持；這些截圖不代表逐章通關或原版畫面對拍。
