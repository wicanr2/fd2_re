# 《炎龍騎士團 2》重製版 v0.1.0 推廣片規格

狀態：`READY`（2026-08-30）。本片介紹第一個公開里程碑，必須使用目前提交
重新錄製的重製執行期，並實際展示正常標題入口、第一關玩家操作與四種官方語言
切換。舊推廣片只能提供已標示的原版比較片段，不得冒充目前重製執行期。

## 權利與發布邊界

- 原版短片只取自使用者提供、未加入版控的保存錄影，畫面須明示「原版 DOS」。
- 重製片段由目前 Linux AppImage 與本機合法分離素材，在一次性 Docker／Xvfb
  容器內以一般鍵盤輸入重新擷取。
- 公開影片不得嵌入原版音樂；底音使用推廣片專用的低音量中性合成音，並標示
  「非原版配樂」。
- GitHub Release 只發布不含原版素材的引擎封包。含完整素材的本機包不得上傳。

## 錄製契約

- 使用 `tools/capture_fd2_v010_gameplay.sh`，輸入為本機 Linux 完整版目錄；輸出
  `dist/promo/fd2-v0.1.0-live-gameplay.mp4`。
- Xvfb 為 1280×800、30 fps；使用軟體渲染。輸入順序固定為略過可略過的開場、
  START、推進第一段劇情、抵達第一關、四次 F4，再送出戰場方向與確認鍵。
- 錄影腳本不得使用 `FD2_CAMP_NODE`、直接進場、強制勝利或畫面注入鉤子。
- 第一關系統選單必須靠近目前游標格；成片不得使用選單退回左上角的舊錄影。
- 動態對拍使用 `tools/build_fd2_ch01_dynamic_compare.sh`，左右明示「原版 DOSBox」
  與「重製版」，並在畫面標示「相近狀態比較」。
- 影片 metadata 必須記錄引擎提交、AppImage SHA-256、輸入序列、錄影工具與
  實際輸出雜湊。

## 成片驗收

- H.264／AAC、1280×720、30 fps；聲音為雙聲道 48 kHz。
- `ffprobe` 驗證串流、時長、解析度與幀率。
- 執行黑畫面、長靜音、音量與凍結檢查；片頭／片尾刻意黑底不算缺陷。
- 依分幕時間抽取接觸表，人工確認原版／重製標籤、四語橫幅、字幕與比例。
- 產出影片 SHA-256 與 JSON metadata；公開封包再獨立執行素材拒絕清單檢查。
